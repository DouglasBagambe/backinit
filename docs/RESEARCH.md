## Tracker and playback

[Sofascore's explanation of Attack Momentum](https://www.sofascore.com/news/how-sofascores-attack-momentum-changed-sport-analysis) treats momentum as an interpretation of match flow. This is distinct from measured ball positions. The initial BackInIt tracker intentionally replays discrete demo events without synthesizing location or proprietary momentum values.

[HLS.js demo](https://hlsjs.video-dev.org/demo/) and [Shaka Player demo](https://shaka-project.github.io/shaka-player/demo/) demonstrate adaptive streaming in browser players. HLS.js is sufficient for the first HLS slice; Shaka is a candidate for DASH/EME later. Direct playback requires a permitted manifest, browser-compatible codecs, CORS on manifests/segments/keys, valid source entitlements and any required authorized license exchange. Iframes depend on provider permission, frame restrictions, cookies and provider UI. An embedded stream is not owned or controlled by BackInIt.

The initial Sintel CDN probe returned HTTP 403. The selected source is [Big Buck Bunny on the Mux-hosted HLS.js test-stream site](https://test-streams.mux.dev/). [Big Buck Bunny / Blender Foundation](https://peach.blender.org/) is an open movie with CC BY 3.0 attribution. This is a public test endpoint, not an availability SLA or permission to claim sports programming. Do not use it as a production broadcast origin. Test CDN availability remains an external dependency.

## Free-first infrastructure

- [Vercel Hobby](https://vercel.com/docs/plans/hobby): non-commercial personal use restriction. Not an approved free commercial launch target.
- [Render free services](https://render.com/docs/free): idle web services sleep after 15 minutes; free Postgres expires after 30 days. Not a durable production database or low-latency always-on sports service.
- Local Node processes and a future local PostgreSQL installation avoid subscriptions. Hosted PostgreSQL alternatives need current quota, connection, storage, backup and commercial-terms evaluation before selection.
- GitHub Actions is configured, but repository/account quota must be monitored. Do not assume unlimited free private-repository CI.

## Official viewing and security — 28 October 2026

- Integrated public RSS/oEmbed from nine official YouTube publishers across seven sports. This supplies selected genuine videos, not broader structured scores or all live broadcasts. [YouTube embedding documentation](https://support.google.com/youtube/answer/171780) covers privacy-enhanced mode, publisher controls and HTTP Referer requirements. See [STREAMS.md](STREAMS.md) for practical free destinations and acquisition requirements.
- [NBA API hub terms](https://api-hub.nba.com/termsofuse) restrict data use; an accessible endpoint is not blanket authorization for a commercial comprehensive/live statistics product. No undocumented NBA scoreboard integration has been enabled on that assumption.
- [TheSportsDB API docs](https://www.thesportsdb.com/docs/api) and [terms](https://www.thesportsdb.com/docs_terms_of_use.php) distinguish shared development access from distributed applications and richer endpoint access. No shared development key is presented as unrestricted production coverage.
- [OWASP password storage guidance](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) informed scrypt N=32768/r=8/p=3 with a bounded hashing queue. [Recovery guidance](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html) informed random, hashed, single-use codes and session revocation after resets. Recovery is offline-code based; email delivery and ownership verification remain absent.
- Real logo provenance is recorded in `apps/web/public/logos/SOURCES.json`. These are publisher/provider marks, not generated artwork. Presence of a logo does not imply affiliation or a broadcast license.

### Identity lookup check — 28 October 2026

The public OpenLigaDB match/team response includes stable `teamId` and `teamIconUrl`; normalization previously discarded the image field. These are now retained. The API's `getavailableteams/pl/2026` is reachable but contains some embedded data images, HTTP URLs and older artwork, so unsafe image forms are not accepted automatically.

Public ESPN team catalogue endpoints returned current English top-flight and NBA team IDs, display names/aliases and `a.espncdn.com` artwork. The adapter also supports NFL/MLB catalogue shapes for relevant team events. This is an **undocumented public metadata interface**, with no SLA or commercial redistribution permission established by accessibility. It is separately switchable and not represented as a licensed global sports-data service. Current cup team badges were checked through the actual browser decoding path. No paid account or provisioning was used. Before public commercialization, confirm applicable metadata/artwork terms or replace the adapter with a provider agreement suitable for that use.

Equipment photo provenance and license links are recorded in `apps/web/public/sports/SOURCES.json` and the linked credits page. These are real existing images, not generated balls or invented team marks. The Camel Live review informed compact grouping/navigation only; no sporting content or feed was copied.
