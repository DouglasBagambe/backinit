# Home and site preferences polish

The root URL renders Home. The BackInIt header/footer brand and mobile Home action link to `/`; `/home` remains a compatible alternate address for the same broader sports overview. Home now starts with an editorial introduction, clear Watch shortcut, and up to three live/upcoming sports broadcasts chosen using Watch’s ranking. It does not make the full catalogue block page rendering. Fixtures and Live remain accessible as the complete schedule and quick live score views. Watch uses a distinct play-button treatment in the main navigation.

Settings now contains real appearance controls, a persisted viewing timezone, saved-event counts/actions, and account/privacy links. Empty saved-event collections do not show a disabled destructive action. Guest account requests are rejected locally when no session cookie exists, allowing device favorites to initialize without depending on backend availability. An authenticated sync failure remains explicit and has a Retry sync action; it is not disguised as success or deleted data.

First-time visitors see a native modal dialog with Accept all and Essential only. Neither Escape nor a close button dismisses it without a choice. Both choices permit viewing. Essential only stores declined and never enables the network advertising scripts; Accept all enables the existing approved formats and caps. Stored choices survive navigation/reload, and Cookie settings allows revision. The Privacy page remains readable without choosing. This replaces the off-screen footer prompt; it does not substitute a browser-level tracking permission or misrepresent consent. Existing sponsored links remain voluntary, labelled external links. No contextual no-consent vendor tag has been supplied or verified, so tracking tags are not reclassified as essential.

Tests cover root/brand Home navigation, settings persistence, mandatory explicit consent, and absence of ad requests under Essential only. Advertising tests intercept network scripts; they never click advertisers or generate billable test impressions. Existing Home tests now target `/home`; general product checks start with a saved essential-only choice, while advertising tests clear it to verify the full new-visitor flow.

Viewer counts use the unmodified upstream figure and refresh with the catalogue, displayed as “2,000 watching”. A stale snapshot stays identified. Extra Watch-page attribution text is removed; the documented API guide does not require it. Original embedded behavior, ads and watermarks remain intact; privacy disclosures retain the third-party identities. These are provider aggregate figures, not BackInIt presence counts. No fake or interpolated viewer updates are generated.
